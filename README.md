# One Path Fashion

A standalone React catalogue for One Path Fashion's chiffon shawl collection.

## Run locally in VS Code

1. Install Node.js 20 or later and pnpm 10 or later.
2. Open this folder in VS Code.
3. In the integrated terminal, run:

   ```sh
   pnpm install
   pnpm dev
   ```

4. Open the local address shown in the terminal (normally `http://localhost:5173`).

## Quality checks

```sh
pnpm typecheck
pnpm lint
pnpm build
```

The production files are written to `dist/`.
